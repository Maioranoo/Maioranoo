## Projeto principal: FlowBoard

**Gerenciador de tarefas full stack com IA integrada.** Você descreve a tarefa com suas palavras, o modelo (Claude, da Anthropic) preenche os campos, e cada tarefa recebe uma sugestão de próximos passos gerada em segundo plano.

- **IA que não derruba o sistema:** se o modelo falha, demora ou fica sem chave, regras locais assumem.
- **Qualidade medida:** avaliação com 21 casos. A IA acertou 100% dos campos, contra 45 a 70% das regras.
- **Custo sob controle:** limites por usuário e por dia, e saída estruturada (JSON Schema) validada no back-end.
- **Produção de verdade:** contas com JWT, modo visitante, PostgreSQL com Flyway, 86 testes com Testcontainers, CI no GitHub Actions.

`Java 17` • `Spring Boot` • `Spring Security` • `PostgreSQL` • `Claude API` • `JavaScript`
